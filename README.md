# GridWitness · 点阵校图台

用实际摄影标板原图核对名义点阵与暗像素中心。设置首点原坐标、行列、水平和垂直原像素间距，以及找点半宽。每个点以指定局部方框中至少三个合格暗像素的算术质心测真实位置。标板未拍到或没有足够点的格留空。

可打开注明合成的练习或导入单帧 PNG、JPEG、TIFF、BMP、WebP。原图点读保持实际 RGB，当前行提供水平、垂直偏移，按行查看实证支持，保存重开、下载实测CSV、原源校样、包含原照片的ZIP，或把照片送准备。

当前行可指定左端、右端候选格列和横向角度限值：系统只在两端都是实测暗点质心、端点之间至少还有四个实测格、连线对原图横向的倾角不超限时采用参考直线；候选连线按“更接近水平”和“覆盖更多真实格”的排名和择优，缺证格不补、不造点。采用后读取两端列之间每个真实质心到该直线的有符号垂直距离（沿线从左往右看，线下方为正、上方为负、线上为零），可在位移图切换“参考线偏离”查看，核格读数保留同一原质心并附偏离值；CSV 增加 `line_offset` 列，PNG 校样标出实际采用直线和证点，ZIP 内 JSON 记录参考线与全部候选。

`docker compose up --build` 后访问 `http://127.0.0.1:19927/`。仅监听本机，命名卷保留数据。
