# GridWitness · 点阵校图台

用实际摄影标板原图核对名义点阵与暗像素中心。设置首点原坐标、行列、水平和垂直原像素间距，以及找点半宽。先在原片上按现有暗阈剔除任一 RGB 通道为 0 或 255 的夹断像素，再把至少三个上下左右相连的合格暗像素组成完整暗组，按整组像素算质心。质心落在某格原搜窗内或边上才可候选；一个暗组最多交给一格，采用格从左到右的真实质心 X 严格递增，无法认领的格留空。多种合法配法时先保更多实格，再让实点更靠近名义中心。核格、当前行偏移读数、CSV 与 PNG 校样共用同一份测量结果。

可打开注明合成的练习或导入单帧 PNG、JPEG、TIFF、BMP、WebP。原图点读保持实际 RGB，当前行提供水平、垂直偏移，按行查看实证支持，保存重开、下载实测CSV、原源校样、包含原照片的ZIP，或把照片送准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19927/`。仅监听本机，命名卷保留数据。
